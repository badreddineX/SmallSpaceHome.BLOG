# SmallSpaceHome (Canada) — Pin-by-Pin Instructions

**The plan:** 3 static pins + 1 short video per blog post. Finish all 4 for a post, check it off, move to the next post. Once all 23 posts have their 4 pieces, we start writing new blog posts and repeat the same process for those.

Design the 3 static pins at **1000×1500px** and the short as a **1080×1920, 15–30 second vertical video**, both in Canva. Upload everything to the Drive folder:
https://drive.google.com/drive/u/2/folders/1IdMYPTweYwrb64STXJO0emPv073rLqpQ
(one subfolder per post, e.g. `/01-how-to-make-a-small-room-look-bigger/pin-1.png`, `pin-2.png`, `pin-3.png`, `short.mp4`)

**Colors (all pins):** Cream `#FAFAF7` background · Deep Sage `#6B8F66` bands/rules · Warm Tan `#C4A882` kicker text · Ink `#1C1917` headline text. Headline font: Playfair Display. Kicker/domain font: Inter. Always end with `smallspacehome.ca` at the bottom, small.

**3 layouts — one per pin, so each of the 3 static pins for a post uses a different layout:**
- **Layout A — Full-bleed:** photo edge-to-edge, dark gradient scrim rising from bottom, white headline over the scrim.
- **Layout B — Split:** photo fills top half, cream text panel below, sage rule above the domain line.
- **Layout C — Framed:** sage-bordered frame on cream, centered text, small photo strip inside the frame.

**Short video format (same for every post):** 3–4 photos from the post in a slideshow, slow pan/zoom on each (Canva's built-in "pan" animation works), headline text overlay in the first 2 seconds using the Pin 1 headline, same colors/fonts as the static pins, ends on the domain line `smallspacehome.ca`. No voiceover needed — text-on-screen only.

**Publishing note:** design all 4 for a post together, but don't publish them the same day — spread across different days/weeks. Save the short for its own day, not bundled with a static pin.

Work top to bottom, one post at a time. Mark `[x]` when a pin or the short is uploaded.
