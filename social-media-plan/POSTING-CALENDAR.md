## 1. The rule: 3 sessions a week to start, Instagram ramps up later

Post **Monday, Wednesday, Friday** (evening, 7–9pm local is the strongest
window on both platforms — if that's not practical, any consistent 3x/week
rhythm works, including starting on a different weekday). Never dump a
whole post's pins in one sitting — that reads as spam to both platforms'
algorithms, especially on new accounts.

**Two-phase frequency plan:**

| Phase | Pinterest | Instagram |
|---|---|---|
| **Phase 1 — first 2-3 weeks** | 3x/week (Mon/Wed/Fri) | 3x/week (same days) — build the habit first |
| **Phase 2 — once the routine feels easy** | 3x/week (no change) | **5-6x/week, or daily** |

**Why they diverge:** Pinterest content is evergreen — a pin can get found
and clicked months later, so 3x/week is enough long-term. Instagram's
algorithm and audience both reward recency/consistency much more heavily,
and Stories are cheap to post (same pin images you already have, just
shared more often) — so once the 3x/week rhythm is second nature, bump
Instagram specifically, not Pinterest. Don't start at daily on Instagram
from day one — a sustainable 3x/week habit beats an ambitious daily
schedule that gets abandoned after two weeks.

**Per blog post: 3 pins + 1 short, spread across a 4-week rollout, one asset
per session:**

| Week | Session | Asset |
|---|---|---|
| 1 | 1st | Pin 1 (Layout A) |
| 2 | 1st | Pin 2 (Layout B) |
| 3 | 1st | The short (once built — see gap note in §5) |
| 4 | 1st | Pin 3 (Layout C) → post retires, a new one starts in this slot |

**Every session posts to Pinterest and Instagram at the same time:**
- **Pinterest:** upload the pin image to the matching category board, with
  the pin description from `PINTEREST-PINS.md` and the destination link
  (always the specific blog post, never the homepage)
- **Instagram:** share the same image to your Story, add a Link sticker
  with the same destination URL, then archive that Story into the matching
  Highlight (Organization / Decor / Storage / Budget Tips)

Start **3 different posts** on 3 different weekly sessions (session 1, 2,
and 3 of week 1), then let each run its own 4-week rollout in parallel —
this fills all 3 weekly slots from week 1 onward, and a new post enters
rotation every ~4 weeks as an older one finishes.

## 4. Quick reference — what to do at each session

1. Check this file for which post/pin is due this session
2. Pull the exact pin image from `pinterest-pins/<slug>-<A|B|C>.png`
3. Pull the exact pin description from `PINTEREST-PINS.md`
4. Get the destination URL: `https://smallspacehome.ca/blog/<post-slug>/`
5. **Pinterest:** new Pin → upload image → paste description → paste link →
   save to the matching category board
6. **Instagram:** share the same image to Story → add Link sticker with the
   same URL → after posting, tap **"Add to Highlight"** → choose the
   matching category Highlight
